# Nunegal mobile device shop prototype

A small React application for browsing mobile devices, viewing specifications, selecting storage and color, and adding a selection through the supplied test API.

## Status

Planning. The source brief is [`Prueba frontend ITX (1).pdf`](./Prueba%20frontend%20ITX%20(1).pdf). The app will have two views: a product list at `/` and product details at `/products/:productId`.

Setup and run instructions will be added with the project scaffold.
